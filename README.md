# Bit Connect Guide

A one-page guide to **Bit Connect**, a community forum, feedback board and public roadmap plugin for WordPress, and its **Pro** add-on.

**Live site:** https://heykhoaiz.github.io/bit-connect-guide/

## What's inside

- **Screenshots**: 28 screens of the community portal, admin, settings, phone and dark mode
- **Get started**: install, set up the portal, grant permissions, organise stages, statuses, topics and tags
- **Upgrade to Pro**: install the add-on, activate the licence, what happens if it expires
- **Free vs Pro**: feature checklists and a side-by-side table
- **SEO and AI search**: link structure, sitemaps, structured data, and how to get cited by AI assistants
- **Built with**: the technology stack, how a portal page loads, and the tools and libraries
- **Use cases**, the **Roadmap** and a searchable **FAQ** of 150 questions, with a Technical category

## Running it locally

It is a static page with no build step. Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Screenshots are from a demo site with sample content.
