Get started

Needs WordPress 6.8 or newer and PHP 8.2 or newer. Setup takes three steps, and a wizard guides you through them.

  1. Install the plugin. In WordPress go to Plugins → Add New → Upload Plugin, choose bit-connect-<version>.zip, then install and activate it. Once Bit Connect is listed on WordPress.org, you can also search for it under Plugins → Add New.
  2. Choose where the community lives. Open Bit Connect in the admin menu and the wizard starts.
    • Own page (recommended), for example yoursite.com/community
    • Homepage: the community replaces your homepage. You can switch back at any time.
  3. Brand it. Set the community title and logo, and choose who can see it: Everyone or Logged-in users only.
  4. Set up sign-in. Use the built-in login and signup forms, or link to your own login pages. You can turn on email verification. Then click Finish Setup.
  5. Give members permission to post. Go to Members → Role permissions. On a new install only administrators can post.
Tip: you can also place the community on any page with the [bit-connect] shortcode or the Bit Connect block.

Organise your forum

Stages

The sections of your forum, such as Questions, Ideas or Bug Reports. Every post sits in one stage.

Statuses

Progress labels, such as Planned, In progress or Done. Use them to run a public roadmap.

Topics

What a post is about, such as Feature request or Announcement. A new forum starts with one topic, Discussion.

Tags

Free-form labels. Members can suggest new tags, and they appear after you approve them.

Upgrade from Free to Pro

Pro is a second plugin that runs alongside the free one. Your posts, members, settings and URLs stay exactly as they are.

  1. Keep Bit Connect (free) active. Pro needs it to run.
  2. Upload Pro. Go to Plugins → Add New → Upload Plugin, choose bit-connect-pro-<version>.zip, and activate it.
  3. Activate your licence. Go to Bit Connect → Support and click Activate License. After activation the menu item reads Support & License. Sign in to Bit Apps in the window that opens. When the window closes, the page reloads with your licence active.
  4. Turn on the features you want. Polls, auto-hide after 2 reports and pinning start on. The rest wait for you to turn them on or set them up.
    • Settings → Posts: private posts, comment upvotes and polls
    • Settings → Moderation: an approval queue for new posts, and auto-hiding content after a set number of reports
    • Settings → Limits: post length, number of files and file size
    • Settings → Notifications: your own email sender and email text
    • Settings → Portal: image banners
    • Groups, a new screen: public and private groups, and the groups that guests see in the sidebar. The sidebar shows its Groups section after you create the first group.
    • Members: badges and permissions for individual members

If the licence expires or Pro is turned off

Licence expiresPro features switch back to the free behaviour. Private groups stay private. You can renew from the licence screen.

      SEO & AI search

      Every public post is a real page. The server sends its full text as plain HTML, with its own title, description, canonical URL and structured data, and lists it in a sitemap. SEO works the same in Free and Pro. Pro adds group pages and keeps private content out of search.

      What gets indexed

      These examples use the portal address example.com/community.

      example.com/community/ post list · indexed · in sitemap ├─ dark-mode-for-the-dashboard/ post · indexed · in sitemap │ └─ comment/482 link to one comment, same page ├─ page/2/ more posts · indexed · not in sitemap ├─ stage/feature-requests/ indexed · in sitemap ├─ tag/billing/ indexed · in sitemap ├─ topic/announcement/ topic · indexed · in sitemap ├─ status/planned/ off by default (can be turned on) ├─ group/beta-testers/ Pro, public group · indexed ├─ group/vip/ Pro, private group · never indexed ├─ user/jane-doe/ profile · off by default └─ login/ · register/ · notifications/ never indexed

      Swipe the box sideways to see each note.

      Search, filter and sort links such as ?search=export point search engines back to the main list, so they never create duplicate pages. If you rename a tag or stage, its old address redirects to the new one.

      Sitemap

      FileWhat it holds
      /bit-connect-sitemap-index.xmlThe main index. It is listed in robots.txt and added to Yoast's index automatically. Submit it in Google Search Console and Bing.
      /bit-connect-sitemap-topics-1.xmlThe community home and every published post, with the date each last changed. Each file holds up to 2,000 links.
      /bit-connect-sitemap-tag-1.xml etc.Each stage, tag, topic or group page you chose to index, if it has posts
      /wp-sitemap.xmlThe WordPress sitemap, which includes the same links
      Never in the sitemap: profiles, extra list pages, account pages, empty or unapproved tags, hidden posts, private posts and private groups. The sitemap only appears when the community is public and Settings → Reading → Discourage search engines is off.

      What each page tells search engines

      SignalWhat Bit Connect outputs
      TitleThe post title, then the community name
      DescriptionTaken from the post text or the archive description
      CanonicalOne clean URL for each page
      Social cardsOpen Graph and Twitter tags: title, description, image
      Structured dataDiscussionForumPosting for each post, with its author, vote count and up to 20 comments, plus breadcrumbs. Lists use CollectionPage.
      SEO pluginsYoast, Rank Math, AIOSEO and SEOPress are detected. Bit Connect writes the tags on community pages so you never get duplicates.

      How to get cited by ChatGPT, Perplexity, Gemini and Claude

      AI assistants quote pages they can read as plain text. Bit Connect handles that technical part, so the rest comes down to how you write.

      • Title posts as questions. "How do I export invoices to CSV?" gets matched much more often than "Export issue".
      • Answer in full sentences in the first comment. Assistants quote short answers that make sense on their own. With Pro, pin the best comment to the top.
      • Use statuses as a public changelog. When you move a request to Done, add a dated comment. That gives assistants a fresh fact to cite.
      • Describe every stage, topic and tag. The description becomes the archive page's meta description.
      • Keep the community public. A members-only community is hidden from all search engines.
      • Allow AI crawlers (GPTBot, ClaudeBot, PerplexityBot, Google-Extended) in robots.txt.
      • Link to the community from your homepage, documentation and emails.
      • Optional: add an llms.txt file at your site root that points to the community. Bit Connect does not create this file for you.

      Built with

      Bit Connect is a normal WordPress plugin. It keeps your content in WordPress's own data types where it can, and it adds a modern app on top for the portal and the admin screens.

      The stack

      WordPress

      Posts are a custom post type, comments are WordPress comments, and stages, statuses, topics and tags are taxonomies. Members are your WordPress users and roles.

      PHP backend

      PHP 8.2 or newer, in a service-provider structure. REST controllers validate each request with its own rules class and check the nonce and the user's capability.

      Database

      Five tables of its own, with the bit_connect_ prefix: votes, follows, reports, notifications and the activity log. Pro adds group members, comment votes and poll votes.

      React frontend

      React 18 and TypeScript, built with Vite 6. Two apps: the community portal and the admin panel.

      UI and state

      Ant Design 5 and Tailwind CSS 3 for the interface, Jotai for state, TanStack Query 5 for data, React Router 7 and the Quill 2 editor.

      Server rendering

      PHP sends each portal page as finished HTML, with the WordPress Interactivity API. The React app then starts on top of it.

      How a portal page loads

      1. WordPress gets the request, for example /community/dark-mode-for-the-dashboard/, and Bit Connect's router finds the page.
      2. PHP writes the page. The HTML holds the post text, the comments, the title and meta tags, the canonical URL and the structured data. Search engines and AI crawlers read this.
      3. The browser starts the app. The portal's JavaScript loads as ES modules on portal pages only. It takes over the HTML that PHP sent.
      4. The app talks to the REST API. Votes, comments and filters go to /wp-json/bit-connect/v1/. The page changes at once, without a full reload.

      WordPress APIsCustom post type, taxonomies, comments, REST API, Interactivity API, WP-Cron, wp_mail(), a block and a shortcode

      FrontendReact 18, TypeScript 5, Vite 6, Ant Design 5, Tailwind CSS 3 with a bc- class prefix, Jotai, TanStack Query 5, React Router 7, Quill 2
